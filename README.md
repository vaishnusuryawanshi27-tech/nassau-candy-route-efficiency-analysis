# Nassau Candy Route Efficiency Analysis

## Project Overview

This project analyzes factory-to-customer shipping route efficiency for Nassau Candy Distributor using Power BI and Streamlit.

The goal of this analysis is to identify:
- Efficient shipping routes
- Delay-prone routes
- Geographic bottlenecks
- Ship mode performance
- Regional logistics trends

The project transforms raw shipment data into actionable logistics intelligence.

# Problem Statement

Nassau Candy Distributor lacked visibility into:

- Which shipping routes are consistently efficient
- Which routes experience frequent delays
- Regional shipping performance variations
- Geographic bottlenecks
- Ship mode efficiency differences

Without this visibility, logistics optimization remained reactive instead of data-driven.

# Streamlit Dashboard

The Streamlit dashboard was developed to provide an interactive and user-friendly platform for logistics performance analysis. Users can dynamically explore shipment data through multiple analytical modules and filters.

### Key Features

* Region, State, and Ship Mode filtering
* Shipping lead-time threshold analysis
* Route efficiency benchmarking
* Top and bottom performing route identification
* Geographic bottleneck analysis
* Factory shipping network visualization
* Ship mode performance comparison
* Route-level and state-level performance drill-down
* Interactive charts, KPIs, and summary tables

### Dashboard Modules

* Logistics Performance Overview
* Route Efficiency Analysis
* Geographic Bottleneck Analysis
* Ship Mode Performance Analysis
* Executive Insights and Recommendations
